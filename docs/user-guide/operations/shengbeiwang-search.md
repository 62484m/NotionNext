# 圣杯网搜索收录起步

## 网站地址与站点验证

Notion CONFIG-TABLE 的 LINK 使用 `https://shengbeiwang.org`，不带末尾斜杠。部署环境的 NEXT_PUBLIC_LINK 也应设为相同值。旧文章 slug 保持不变。

必应验证支持 Notion 配置 `SEO_BING_SITE_VERIFICATION` 或环境变量 `NEXT_PUBLIC_SEO_BING_SITE_VERIFICATION`，值为平台提供的 msvalidate.01 内容，不是整个标签。
百度与 Google 使用原有 SEO_BAIDU_SITE_VERIFICATION 和 SEO_GOOGLE_SITE_VERIFICATION 配置。

先登录必应站长工具并添加网站，取得验证值，填入配置并等待部署或页面缓存刷新，再回平台验证。只有平台显示验证成功，才算接入完成。

## 地图与收录

普通服务器部署使用 `/sitemap.xml` 动态路由，避免构建产出的 public/sitemap.xml 覆盖它造成内容长期不更新。静态导出仍生成文件，需要重新导出才能更新。
地图包括公开的 Post 和 Page，排除草稿、隐藏页面、密码页面、菜单、站内搜索和 RSS；重复网址仅保留一条。
lastmod 使用已有修改时间，没有有效日期时不编造更新日期。页面返回 noindex 时仍允许抓取，以便搜索引擎看到该指令。

上线后打开 `https://shengbeiwang.org/robots.txt` 与 `https://shengbeiwang.org/sitemap.xml`，检查 HTTPS、单斜杠、无重复与近期文章完整性，然后在必应提交地图。
用首页、雷系彼女、狂飙巨星以及一篇新手文章作代表样本，在平台 URL 检查中确认可抓取和收录状态。提交地图不等于立即收录。

## 内容与优惠券

已发布文章沿用原 URL；两篇修订草稿核对后更新原页面，不把修订副本另行发布。
文章保留事实来源和核查边界，不编造亲测。价格、参数、库存和套餐以当前商家资料为准。
继续使用既有淘宝二级页短链 `https://s.tb.cn/c.0xr0s3`，保留手机唤起路径。推广链接仅增加 sponsored 标记，不重写目的地址。
自有统计中转链接与新增点击事件按运营者要求留待后续，本次 SEO 变更不启用。

## 每周复盘

记录相同完整时间区间内的搜索曝光、点击、带来访问的搜索词和落地文章。先以必应站长工具和 51LA 为来源，无法读取的指标留空，不记成 0。
有曝光但少点击，先检查标题是否准确回答搜索问题；有访问但无合适商品内容，先改善文章与实际在售产品的相关性。
当前二级页有两张优惠券，网站端无法直接知道用户最终选择哪张券或是否成交。
